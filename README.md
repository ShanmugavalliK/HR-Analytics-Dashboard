# HR Analytics Dashboard

## Project Overview
The HR Analytics Dashboard is an interactive and data-driven Power BI project designed to provide comprehensive workforce insights and support strategic HR decision-making. This dashboard helps analyze employee demographics, promotion eligibility, retrenchment status, workforce distribution, job satisfaction, overtime trends, and service year analysis through dynamic visualizations and KPI tracking.

The project focuses on transforming raw HR data into meaningful business insights using Power BI, DAX calculations, and data visualization techniques. The dashboard is structured into multiple pages for detailed analysis, enabling HR teams and management to monitor workforce performance, identify employee trends, and improve organizational planning.

---

## Objectives
- Analyze overall employee distribution across the organization
- Monitor promotion eligibility and retrenchment status
- Evaluate workforce demographics and gender distribution
- Understand employee service year trends
- Analyze job satisfaction and overtime patterns
- Provide department-wise and role-wise workforce insights
- Build an interactive dashboard for HR reporting and decision-making

## Dashboard Features

### Home Page
The Home page provides a high-level summary of workforce insights including:
- Total Employees
- Gender Distribution
- Employees Due for Promotion
- Employees Not Due for Promotion
- Employees Currently in Service
- Retrenched Employees
- Service Year Distribution
- Job Level Analysis
- Distance Status Analysis

### Action Page
The Action page focuses on operational HR actions and employee-level tracking:
- Employees Due for Promotion
- Employees Marked for Retrenchment
- Employee-wise action tables
- Detailed workforce action monitoring

### Detail Page
The Detail page provides deeper analytical insights including:
- Department-wise Promotion & Retrenchment Analysis
- Job Satisfaction Analysis
- Overtime Distribution
- High Rating vs Low Rating Employees
- Job Role Details
- Role-wise Employee Metrics
